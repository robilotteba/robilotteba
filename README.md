```yaml
aprendiendo: [Pentesting web, Escalada de privilegios Linux, SIEM, Análisis de logs]
plataformas: [TryHackMe, HackMyVM, EducaciónIT]

```

Estoy construyendo mi camino en **seguridad informática** desde los dos lados:

- 🔴 **Red Team** → atacar máquinas vulnerables en entornos legales, resolver CTFs y entender cómo piensa un atacante.
- 🔵 **Blue Team** → monitorear, detectar y responder: SOC, SIEM, análisis de logs y tráfico.

Este GitHub es mi **cuaderno de estudio público**: cada máquina que resuelvo, cada herramienta que aprendo y cada concepto que entiendo queda documentado acá.
