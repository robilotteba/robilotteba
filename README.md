## 📜 Comandos más usados

> Mi referencia rápida del día a día administrando infraestructura. Desplegá cada bloque.

<details>
<summary><b>🐧 Linux / SysAdmin</b></summary>

```bash
# Sistema y recursos
systemctl status <servicio>        # estado de un servicio
journalctl -u <servicio> -f        # logs en vivo
df -h && free -h                   # disco y memoria
top / htop                         # procesos en tiempo real
ss -tulnp                          # puertos a la escucha

# Usuarios y permisos
id <usuario>                       # grupos y uid
chmod / chown                      # permisos y propietario

# Red
ip a                               # interfaces
ping / traceroute / dig <host>     # conectividad y DNS

# Logs útiles
tail -f /var/log/syslog
grep "error" /var/log/<app>.log
```
</details>

<details>
<summary><b>🪟 Windows / PowerShell</b></summary>

```powershell
# Sistema
Get-Service | Where-Object {$_.Status -eq "Running"}
Get-Process | Sort-Object CPU -Descending | Select -First 10
systeminfo

# Active Directory
Get-ADUser -Filter * -Properties LastLogonDate
Get-ADComputer -Filter *
New-ADUser / Set-ADUser / Disable-ADAccount

# Red
Test-NetConnection <host> -Port 443
Get-NetIPConfiguration

# Eventos (seguridad / sistema)
Get-EventLog -LogName Security -Newest 20
```
</details>

<details>
<summary><b>☁️ Cloud (Azure CLI / AWS CLI)</b></summary>

```bash
# Azure
az login
az vm list -o table
az vm start --name <vm> --resource-group <rg>
az account show

# AWS
aws configure
aws ec2 describe-instances --output table
aws s3 ls
```
</details>

<details>
<summary><b>⚙️ Ansible</b></summary>

```bash
ansible all -m ping                       # verificar conectividad
ansible-inventory --list                  # ver inventario
ansible-playbook playbook.yml --check     # dry-run
ansible-playbook playbook.yml -l <grupo>  # aplicar a un grupo
```
</details>

<details>
<summary><b>🐳 Docker (contenedores)</b></summary>

```bash
docker ps -a                       # contenedores
docker logs -f <contenedor>        # logs en vivo
docker exec -it <contenedor> bash  # entrar al contenedor
docker compose up -d               # levantar stack
```
</details>
