🚀 Cómo verlo en local
```bash
pip install -r requirements.txt
mkdocs serve
# abrir http://127.0.0.1:8000
```
🛠️ Cómo se publica
Cada `push` a la rama `main` dispara el workflow de GitHub Actions
(`.github/workflows/deploy.yml`) que construye el sitio y lo publica en GitHub Pages.
> Ver [GUIA-DE-PUBLICACION.md](GUIA-DE-PUBLICACION.md) para los pasos de puesta en marcha.
